# Installation

## Requirements

- Node.js `>=20.18.1`
- A reachable PhotoPrism instance
- A PhotoPrism API key with access to the target album

## Install The Module

```bash
cd ~/MagicMirror/modules
git clone https://github.com/HeikoGr/MMM-Photoprism2.git
cd MMM-Photoprism2
npm install
```

Continue with [Quick Start](Quick-Start).
